14. SECURITY — CRITICAL
==================================================

Diamond rewards have real value inside RIMILIVE.

Therefore:

DO NOT trust the Android client to award itself Diamonds.

or

be server-authoritative / trusted-backend controlled.

The reward operation should be atomic/idempotent:

1. Verify referral qualifies.
2. Verify this referral has not already been rewarded.
3. Record qualification.
4. Add exactly 11,000 Diamonds to inviter wallet.
5. Record exactly 11,000 as Invite reward earnings.
6. Mark the reward transaction completed.

The same qualification event must never pay twice.

If secure server-side functionality is not currently available:

DO NOT pretend it is complete.

Implement only the safe parts available and report:
